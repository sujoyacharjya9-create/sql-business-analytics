SQL Sales Data Analysis Using MySQL

1. Project Introduction

This project focuses on analyzing retail sales data using MySQL to discover useful business insights. It explores sales performance, customer purchasing patterns, product trends, and revenue generation.

The main objective is to apply SQL concepts to a practical business dataset and convert raw sales records into meaningful information that can support business decisions.

Throughout this project, different SQL techniques are used, including JOINs, aggregate functions, subqueries, Common Table Expressions (CTEs), and window functions.

2. Dataset Information

The project uses multiple related datasets representing different aspects of a retail business.

Table Name| Description
sales| Contains individual sales transaction records
product_lookup| Stores product information, prices, and categories
customer_lookup| Contains customer-related details
category_lookup| Provides product category information
subcategory_lookup| Maps products to their respective subcategories

Important Dataset Columns

- OrderDate: Date when the transaction occurred.
- ProductKey: Unique identifier assigned to each product.
- CustomerKey: Unique identifier assigned to each customer.
- OrderQuantity: Number of units purchased.
- ProductPrice: Selling price of a product.

Revenue is calculated using the following formula:

Revenue = OrderQuantity × ProductPrice

5. Sample SQL Queries

Revenue Generated by Each Customer

SELECT
    s.CustomerKey,
    SUM(s.OrderQuantity * p.ProductPrice) AS total_spent
FROM sales s
JOIN product_lookup p
    ON s.ProductKey = p.ProductKey
GROUP BY s.CustomerKey;

Cumulative Revenue Analysis

SELECT
    OrderDate,
    SUM(s.OrderQuantity * p.ProductPrice) AS daily_revenue,
    SUM(SUM(s.OrderQuantity * p.ProductPrice))
        OVER (ORDER BY OrderDate) AS running_total
FROM sales s
JOIN product_lookup p
    ON s.ProductKey = p.ProductKey
GROUP BY OrderDate;

6. Key Business Findings

The analysis focuses on identifying important patterns in retail sales:

- A relatively small group of customers can account for a significant portion of total revenue.
- Some product categories contribute more to overall sales than others.
- Revenue trends can reveal seasonal patterns and changes in customer demand.
- Identifying high-value customers can help businesses develop better customer retention strategies.
